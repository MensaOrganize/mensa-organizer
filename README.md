# Mensa Organizer

Hackdays-Prototyp für das Gymnasium Wertingen.

## Neu in dieser Version
- feste Preise für alle Speisen
- Gesamtbetrag im Warenkorb
- Gesamtbetrag wird serverseitig berechnet und gespeichert
- Bestellbestätigung enthält Bestellnummer und Hinweis auf Barzahlung an der Kasse
- Mentos wurde durch Cookie ersetzt
- Cookie: Hell / Dunkel
- neues, jugendlicheres Design mit Rot-/Creme-/Anthrazit-Farbwelt passend zur aktuellen Website des Gymnasiums Wertingen
- drei Infokarten weiter nach unten gesetzt
- neuer Slogan: „Weniger Stress. Mehr Genuss!“
- Food-Fotos als Kartenhintergründe von Unsplash
- Mitarbeiterbereich zeigt die gespeicherte Summe

## Abholzeiten
Vor dem Absenden einer Bestellung muss eine Abholzeit ausgewählt werden:
- 1. Pause
- 2. Pause
- Mittagspause

Die Auswahl wird in der Bestellung gespeichert und im Mitarbeiterbereich angezeigt. Der Server akzeptiert ausschließlich diese drei Abholzeiten.
